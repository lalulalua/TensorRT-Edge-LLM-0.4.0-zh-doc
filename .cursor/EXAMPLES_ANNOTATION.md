本项目旨在对 `tensorrt-edge-llm` 仓库下的 `example` 目录进行深度的本地化和工程化梳理。通过补充底层逻辑注释、重构子模块说明文档以及更新主项目大纲，提升整个边缘侧部署框架的可读性与维护性。

## 2. 任务范围
- **代码目录**：`example/` 及其所有嵌套子目录（涵盖 `accuracy`, `llm`, `multimodal`, `utils` 等）。

- **全局文件**：项目根目录的主 `README.md`。

## 3. 具体执行规范

### 3.1 深度代码注释 (Code Annotation)
- **目标**：为核心推理逻辑、显存分配策略和算子调度添加专业中文注释。
- **重点关注**：涉及 Activation Buffer 管理、Zero-copy 预处理、CUDA Graph 构建以及 engine 文件反序列化的代码段。
- **要求**：揭示代码的“系统级意图”与“数据流转规律”，绝不仅仅是字面翻译。保持命名空间、变量名和底层 API（如 TensorRT Plugin）的英文原貌。

### 3.2 子模块 README 构建机制 (Sub-README Mechanism)
- **触发条件**：遍历所有层级的文件夹，只要检测到 `CMakeLists.txt` 文件，即触发文档生成逻辑。
- **重命名策略**：若目标目录下已存在原生 `README.md`，必须将其无损重命名为 `README_en.md`。
- **生成策略**：在目标目录下新建纯中文 `README.md`。内容需包含：模块功能定位、CMake 构建配置解析、核心依赖关系说明。

### 3.3 架构与数据流图绘制 (Mermaid Flowcharts)
- **主流程图**：在每个新建的中文 `README.md` 中，使用 Mermaid 语法绘制端到端的数据流转图（输入 -> 预处理 -> engine 推理 -> 后处理 -> 输出）。
- **子流程图**：针对包含复杂策略（如混合精度调度、特定解码算法）的子模块，按需绘制细化的内部流转逻辑图。

### 3.4 主 README 增量更新 (Main README Update)
- **项目溯源**：在主 `README.md` 顶部或介绍章节，清晰说明本项目的开源来源及背景。

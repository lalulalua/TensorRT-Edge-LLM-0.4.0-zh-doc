# 文档中文化任务要求

## 目标
将本项目 `docs/` 目录下的所有英文文档，以及根目录的 `README.md`，精准翻译并迁移为中文版本。

## 执行步骤
1. **结构镜像**：在根目录创建 `docs_zh/` 文件夹。
2. **逐一翻译**：读取 `docs/` 下的每一个 `.md` 文件，参考 `.cursorrules` 中的翻译规范，将其翻译后写入 `docs_zh/` 同名文件中。
3. **主页翻译**：读取根目录的 `README.md`，翻译后生成 `README_CN.md`。
4. **技术校验**：在翻译过程中，请结合当前项目的核心代码逻辑，检查原英文文档中提及的参数、API 调用是否已经过时；如果发现文档与实际代码不符，请在中文版中给出客观的修正描述。

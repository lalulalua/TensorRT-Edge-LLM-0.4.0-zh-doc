# 快速入门

> **代码仓库：** [github.com/NVIDIA/TensorRT-Edge-LLM](https://github.com/NVIDIA/TensorRT-Edge-LLM)

> 若使用 NVIDIA DRIVE 平台，请参阅随 DriveOS 发行版提供的文档。

本快速入门帮助你在约 15 分钟内上手 TensorRT Edge-LLM。

## 前置条件

- NVIDIA Jetson Thor
- JetPack 7.1
- 用于下载模型的互联网连接
- 带 GPU 的 x86 Linux 主机，用于模型导出

## 步骤 1：克隆仓库（在 x86 主机与设备上均需执行）

```bash
git clone https://github.com/NVIDIA/TensorRT-Edge-LLM.git
cd TensorRT-Edge-LLM
git submodule update --init --recursive
```

## 步骤 2：安装 Python 包（在 x86 主机上）

```bash
# 安装 Python 包及全部依赖
pip3 install .
```

将安装 Python 导出工具及所需依赖。

## 步骤 3：构建 C++ 工程（在设备上）

请通过 JetPack 安装 CUDA 与 TensorRT。TensorRT 应安装在 `/usr` 目录下。

```bash
# 如需则安装系统构建工具
sudo apt update
sudo apt install cmake build-essential

# 构建工程
mkdir build
cd build
cmake .. \
    -DTRT_PACKAGE_DIR=/usr \
    -DCMAKE_TOOLCHAIN_FILE=cmake/aarch64_linux_toolchain.cmake \
    -DEMBEDDED_TARGET=jetson-thor
make -j$(nproc)
```

**说明**：所有 Edge 设备构建均需指定工具链文件与嵌入式目标。

将构建：

- C++ 引擎构建器应用
- C++ 运行时与示例

## 步骤 4：下载并导出模型（在 x86 主机上）

以轻量示例 [Qwen3-0.6B](https://huggingface.co/Qwen/Qwen3-0.6B) 为例：

```bash
# 量化为 FP8（会自动下载模型）
tensorrt-edgellm-quantize-llm \
    --model_dir Qwen/Qwen3-0.6B \
    --output_dir ./quantized/qwen3-0.6b \
    --quantization fp8

# 导出为 ONNX
tensorrt-edgellm-export-llm \
    --model_dir ./quantized/qwen3-0.6b \
    --output_dir ./onnx_models/qwen3-0.6b
```

## 步骤 5：构建 TensorRT 引擎（在 Thor 设备上）

将整个 ONNX 文件夹拷贝到 Thor 设备后：

```bash
./build/examples/llm/llm_build \
    --onnxDir ./onnx_models/qwen3-0.6b \
    --engineDir ./engines/qwen3-0.6b
```

构建时间：约 2–5 分钟

## 步骤 6：运行推理

创建输入文件 `input.json`，写入你的提示：

```json
{
    "batch_size": 1,
    "temperature": 1.0,
    "top_p": 1.0,
    "top_k": 50,
    "max_generate_length": 128,
    "requests": [
        {
            "messages": [
                {
                    "role": "user",
                    "content": "What is the capital of United States?"
                }
            ]
        }
    ]
}
```

然后运行推理：

```bash
./build/examples/llm/llm_inference \
    --engineDir ./engines/qwen3-0.6b \
    --inputFile input.json \
    --outputFile output.json
```

**输入格式：** 与 OpenAI API 格式高度一致。更多说明见 `examples/llm/INPUT_FORMAT.md`。示例输入见 `tests/test_cases/`（例如 `llm_basic.json`）。

**完成** 查看 `output.json` 中的模型回复。

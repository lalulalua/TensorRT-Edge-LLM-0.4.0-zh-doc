# 安装

> 若使用 NVIDIA DRIVE 平台，请参阅随 DriveOS 发行版提供的文档。


TensorRT Edge-LLM 包含两个需在不同系统上安装的独立组件：

1. **Python 导出流水线**（在带 GPU 的 x86 主机上运行）
2. **C++ 运行时**（在边缘设备上构建与运行）

---

## 第一部分：Python 导出流水线（x86 主机 + GPU）

Python 导出流水线用于转换与量化模型，必须在带 NVIDIA GPU 的 x86 Linux 系统上运行。

### 系统要求

- **平台**：x86-64 Linux
- **推荐系统**：Ubuntu 22.04、24.04
- **GPU**：NVIDIA GPU（用于模型量化）
- **CUDA**：12.x 或 13.x
- **Python**：3.10+

### 安装步骤

**1. 克隆仓库**

```bash
git clone https://github.com/NVIDIA/TensorRT-Edge-LLM.git
cd TensorRT-Edge-LLM
git submodule update --init --recursive
```

**2. 安装 Python 包**

```bash
# 建议创建虚拟环境
python3 -m venv venv
source venv/bin/activate

# 安装包及全部依赖
pip3 install .
```

将安装全部所需 Python 依赖，包括：

- PyTorch
- Transformers
- NVIDIA Model Optimizer
- ONNX
- 以及其他依赖

> **说明：** 具体版本要求请参阅仓库根目录的 `requirements.txt` 与 `pyproject.toml`。

**3. 验证安装**

```bash
# 测试导出工具
tensorrt-edgellm-export-llm --help
tensorrt-edgellm-quantize-llm --help
```

**导出流水线环境已就绪。** 接下来可导出与量化模型；ONNX 文件需拷贝到边缘设备以部署运行时。

---

## 第二部分：C++ 运行时（边缘设备）

C++ 运行时在目标边缘设备上构建并执行模型，必须在目标平台或其交叉编译环境中构建。

### 系统要求

**目标平台：**

- NVIDIA Jetson Thor
- JetPack 7.1
- CUDA 13.x（随 JetPack 提供）
- TensorRT 10.x+（随 JetPack 提供）

### 构建说明

**1. 安装系统依赖（在边缘设备上）**

```bash
sudo apt update
sudo apt install -y \
    cmake \
    build-essential \
    git
```

**2. 确认 CUDA 与 TensorRT 安装**

安装 JetPack 后，TensorRT 应位于 `/usr`：

```bash
# 查看 CUDA 版本
nvcc --version  # 应显示 CUDA 13.x

# 查看 TensorRT 版本
dpkg -l | grep tensorrt  # 应显示 TensorRT 10.x+
```

**3. 克隆仓库（在边缘设备上）**

```bash
git clone https://github.com/NVIDIA/TensorRT-Edge-LLM.git
cd TensorRT-Edge-LLM
git submodule update --init --recursive
```

**4. 配置构建**

```bash
mkdir build
cd build

# 面向边缘平台时需要工具链与嵌入式目标
cmake .. \
    -DCMAKE_BUILD_TYPE=Release \
    -DTRT_PACKAGE_DIR=/usr \
    -DCMAKE_TOOLCHAIN_FILE=cmake/aarch64_linux_toolchain.cmake \
    -DEMBEDDED_TARGET=jetson-thor

# 若仅在 GPU 上开发（SM80、86、89、120）— 无需工具链或嵌入式目标。

cmake .. \
    -DCMAKE_BUILD_TYPE=Release \
    -DTRT_PACKAGE_DIR=/path/to/TensorRT \
    -DCUDA_VERSION=13.0
```

**CMake 选项：**

| 选项 | 说明 | 默认 |
|:-------|:------------|:--------|
| `TRT_PACKAGE_DIR` | TensorRT 安装路径 | 必填 |
| `CMAKE_TOOLCHAIN_FILE` | **边缘设备必填**：边缘构建使用 `cmake/aarch64_linux_toolchain.cmake`。**GPU 本地构建不需要** | N/A |
| `EMBEDDED_TARGET` | **边缘设备必填**：目标平台（`jetson-thor`）。**GPU 本地构建不需要** | N/A |
| `CUDA_VERSION` | CUDA 版本（如 13.0），用于匹配目标平台 | 13.0 |
| `BUILD_UNIT_TESTS` | 是否构建单元测试 | OFF |

> **支持的 GPU 架构与计算能力**，见 [支持的模型 - 平台兼容性](02_Supported_Models.md#platform-compatibility)

**5. 构建工程**

```bash
make -j$(nproc)
```

构建时间视硬件约 1–2 分钟。

**6. 验证构建**

```bash
# 测试 C++ 示例
./examples/llm/llm_build --help
./examples/llm/llm_inference --help
```

**C++ 运行时环境已就绪。** 可在边缘设备上构建引擎并运行推理。

## 完整工作流摘要

**在 x86 主机（导出流水线）：**

1. 安装 Python 包
2. 导出并量化模型
3. 将 ONNX 文件传到边缘设备

**在边缘设备（C++ 运行时）：**

1. 构建 C++ 运行时
2. 由 ONNX 构建 TensorRT 引擎
3. 运行推理

端到端示例见 [快速入门](01.2_Quick_Start_Guide.md)。

## 故障排除

### 常见安装问题

**问题：Python 包导入错误**

解决：确认已激活虚拟环境且已安装包：

```bash
python3 -m venv venv
source venv/bin/activate
pip3 install .
```

**问题：`nvcc: command not found`**

解决：确认已正确安装 JetPack 7.1 且包含 CUDA：

```bash
nvcc --version
# 应显示 CUDA 13.x
```

**问题：CMake 阶段提示找不到 TensorRT**

解决：指定 TensorRT 包目录。该目录须包含 `lib` 与 `include`，且能找到 `nvinfer` 库与头文件：

```bash
cmake .. \
    -DTRT_PACKAGE_DIR=/usr/local/TensorRT-10.x.x \
    -DCMAKE_TOOLCHAIN_FILE=cmake/aarch64_linux_toolchain.cmake \
    -DEMBEDDED_TARGET=jetson-thor
```

**问题：C++ 构建时出现线程相关问题**

解决：降低并行度或串行构建：

```bash
make -j  # 替代 make -j$(nproc)
```

## 卸载

**Python 导出流水线（x86 主机）：**

- 退出并删除虚拟环境：`deactivate && rm -rf venv`
- 可选删除仓库：`rm -rf TensorRT-Edge-LLM`

**C++ 运行时（边缘设备）：**

- 删除构建目录：`rm -rf build`
- 可选删除仓库：`rm -rf TensorRT-Edge-LLM`
